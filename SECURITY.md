# Security policy

## Scope

The Sharks is an instruction-only project. It does not require API keys, collect pitch data, connect to customer systems or run a hosted service.

## Reporting

Please do not open a public issue containing credentials, private business information or personal data. Contact the repository maintainer privately through the GitHub profile and include:
- A concise description of the issue.
- Steps to reproduce, if applicable.
- A safe proof of concept without real secrets or customer data.
- Potential impact and any suggested mitigation.

## Safe use

- Never commit `.env` files, API keys, access tokens or private pitch decks.
- Do not paste confidential customer or employee data into an AI tool unless you have authorization and the provider's data terms are appropriate.
- Verify AI-generated competitor, legal, financial and market claims independently.
