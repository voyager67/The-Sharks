# Operating playbook

1. Give the panel a clear pitch and whatever evidence exists.
2. Each Shark asks exactly one high-information question.
3. Answer with facts where possible; label estimates and unknowns honestly.
4. Each Shark issues IN or OUT with one evidence-linked reason and a change-my-mind condition.
5. THE SHARKS reports the Deal Meter, strongest/weakest evidence, KILL SHOT and a ranked Fix List.
6. Run tests, bring back results and type `PITCH AGAIN`.

Use `SPEED ROUND` for a fast provisional review or `ASK MINT`, `ASK MAGNET`, `ASK LEDGER`, `ASK RAZOR` or `ASK FORGE` for a single specialist view.

A hypothetical investment offer is a fictional exercise only, never a real offer, valuation or financial recommendation.
